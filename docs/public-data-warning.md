# אזהרת אבטחה — מקור נתונים ציבורי

הפרויקט ממשיך להשתמש ב-GitHub ציבורי ובקובצי Git LFS ציבוריים, בהתאם להחלטה שניתנה במהלך העבודה.

## המשמעות

- התחברות, קוד גישה ו-Render יכולים להגביל את ממשק האתר ואת בקשות השרת.
- הם **אינם יכולים להגן על הנתונים עצמם** כאשר קובצי הנתונים או אובייקטי ה-LFS זמינים מכתובות ציבוריות.
- אדם יכול לעקוף את הממשק ולנסות להוריד את הקבצים ישירות מ-GitHub/‏LFS.
- לכן אין להציג את המערכת כמאגר סגור או כגבול אבטחה מלא.

## מה כן מוגן

- מפתחות וסודות נשארים בשרת ואינם נצרבים ב-Frontend.
- מסלולי Render מוגנים יכולים לדרוש session וקוד גישה.
- קובצי audit ופעולות ניהול נשארים בצד השרת.

## כדי לקבל הגנה מלאה בעתיד

יש להעביר את הנתונים למקור פרטי, למשל אחסון פרטי בשרת/‏R2 או repository פרטי, ולתת ל-Render להגיש טווחי נתונים רק אחרי הרשאה.
